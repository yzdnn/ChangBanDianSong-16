## **～项目概述～**
  
「长坂点宋 16」是基于 「[KHドットフォントシリーズ](http://jikasei.me/font/kh-dotfont/)」中的「KHドット道玄坂16」增补部分简繁体汉字的 16px 点阵粗宋体，适合在复古风格的游戏和招牌中使用。

与「长坂点宋 12」不同，本项目分为了简体字形版（SC后缀）和繁体字形版（TC后缀）两种版本。

欢迎对本项目提出宝贵的意见。
